## Неизменяемый production-контракт

- ORBITAL: три уровня по 12 позиций, фазы 0°/15°/0°, радиусы 1,75/3/4,25; внутри 6 O/6 M, снаружи по 12 O. Старт: внутренняя орбита, пистолет, общий лимит 3. Открытия, оружие и DMG/FR/2X/RIC — существующие награды/запас.
- Q/E вращают всю конструкцию с энергией; FIXED наружу без auto-aim/проверки цели; в покое автовращения нет. Shift — production Bullet Time; WASD/Space/ПКМ сохранены. Без сжатия колец/Core I–III/lab slow rings.
- **Расхождение со старой записью:** SegmentedModuleTargets выбирает соседние стреляющие O того же уровня (O–M–O, с замыканием); M усиливает одну/две соседние пушки. Near/Skip/межуровневые связи не восстанавливались. 2X — дополнительный выстрел самой пушки, независимый cooldown 0,5 с на M/пушку, без рекурсии; ограничения DMG/FR/RIC сохранены.
- Tab — существующий конструктор с полной паузой, запас и drag/drop между ячейками. Модальные окна, смерть, переходы и финал блокируют редактирование. Карточки автоматически конструктор не открывают: закрыть карточку/F1 → Tab → установка.
- Всё спорное — default OFF, opt-in только Editor/Development через существующий F1 настоящего MVP. Development ставится до включения/создания, не снимается после OFF, не даёт production-победу/прогресс. Новые публичные профили/баланс/сохранения не вводились. Использованы существующие sprites/animation/VFX, без смены палитры, Rocket Storm и предупреждений.

## Интегрированные playable эксперименты

Шесть ответов исходных гипотез сокращены ниже: GDD/пробел; до → после и решение; ORBITAL; отличие; встраивание/получение; успех, границы и отказ. Общий ORBITAL-контракт выше действует для каждого среза. Это готовность к человеческой пробе, не утверждённый дизайн или доказанное улучшение ощущений.

### Возврат промаха — `miss-return-pistol-experiment` (cycle-58–62)

1. **GDD/пробел:** §2.1/2.2, §4.3–4.5, §5.5, §10.3; пистолету не хватает пространственной специализации.
2. **Гипотеза:** 8 м прямо → 4 м наружу и только после полного промаха 4 м обратно по фиксированной мировой линии. Игрок заводит преследователя на старую линию или направляет следующий выстрел Q/E; цена — потеря прямой дальности. Урон/скорость/cadence прежние, возврат не следует за игроком/станцией/целью.
3. **ORBITAL:** DMG/FR/2X/RIC штатные; 2X создаёт независимый снаряд. Контакт тела отменяет возврат до damage/pierce/RIC, щит поглощает.
4. **Отличие:** условное второе пространственное окно, не homing/новый множитель/клон Relay/Corridor/Rocket Storm.
5. **Интеграция:** OrbitalWeaponSettings runtime clone, ProductionOrbitalCombatAdapter pooled Projectile, RunState/Station/F1. Использовать стартовый пистолет либо обычную награду → запас → Tab. ON/OFF меняют будущие выстрелы, сохраняя cooldown, identity/upgrades/mount и уже летящие; поля очищаются при reuse/Release. Существующий RunState переносит флаг.
6. **Успех/границы/отказ:** cycle-61 — три Passed, включая world-line/body-RIC/pool, opt-in/перенос и настоящий F1/MVP. Пауза не тратит путь; большой Tick заканчивается на развороте, обратный sweep со следующего Tick. Отказ: возврат незаметен либо только ухудшает дальность без решения о движении. PNG не доказывает направление/плавность; это проверено сценарием, ощущения — человеком.

**Проба:** Development MVP → F1 → первая вкладка → «Эксперимент: возврат промаха» → включить → закрыть F1 → стрелять стартовым пистолетом, двигаться поперёк старой линии; сравнить OFF.

### Импульсная пила — `pulsed-saw-experiment` (cycle-17–20)

1. **GDD/пробел:** §2.1, §4.3–4.5, §5.5, §10.3; непрерывный контакт не предлагает окна сближения.
2. **Гипотеза:** постоянный контакт → 0,8 с вращения/контактного радиуса ×1,35, затем 0,4 с обычного размера без вращения и урона. Сближаться в активное окно, отходить в восстановление; урон и ContactHitInterval не усилены.
3. **ORBITAL:** прежние mount/identity/радиусы орбит/управление; ограничения целей M не меняются. Shooting DMG для Saw не разрешался: lifecycle использует штатный ContactSize ×1,15.
4. **Отличие:** временное окно контакта, читаемое существующими масштабом и spin, не переименованный модификатор/событие.
5. **Интеграция:** OrbitalSawModule, сериализуемый флаг попытки, Station/F1. Установленные/последующие Saw и перенос между секторами — один штатный путь. Выключить инерционную пилу; F1 включить импульсную → получить Saw наградой → закрыть карточку/F1 → Tab → O.
6. **Успех/границы/отказ:** фазовая механика и настоящий MVP capture Passed cycle-19, lifecycle Passed cycle-20. Tick продвигает фазу, ActivateCombat читает; пауза замораживает. Toggle/Attach/Detach/teardown сбрасывают фазу, но фазовые переходы не очищают nextHit; дедупликация/щиты прежние. Отказ: фазы не читаются либо восстановление выглядит случайным отказом и не создаёт решения. Кадры показывают размеры, врагов рядом нет; остановка вращения подтверждается сценарием, не PNG.

### Картечный таран — `ram-slug-shotgun-experiment` (cycle-70–75)

1. **GDD/пробел:** §2.1/2.2, §4.3–4.5, §5.5, §10.3; нет короткой линии последовательного оттеснения.
2. **Гипотеза:** 7 дробин/42° → один снаряд: Damage=10, Range=3,5, Speed=7, три тела, Knockback=5, Spread=0, Pellets/BurstShots=1, прежний FireInterval. Направлять Q/E короткую линию и вести в неё толпу ценой покрытия/дальности.
3. **ORBITAL:** прежние модификаторы/энергия/FIXED/Shift/Tab; 2X — отдельный снаряд без сброса ordinary cooldown. Щит не обходится; импульс только выжившим поддерживаемым EnemyChaseMovement, максимум 5.
4. **Отличие:** последовательные тела и пространственный импульс медленной короткой линии, не DMG/FR/2X/RIC/событие. Существующее тело ×1,6, отдельная копия Presentation, цвет/стиль прежние.
5. **Интеграция:** штатный Shotgun → награда → запас → Tab/O, settings clone, RunState/Revision, Station/F1, прежний contact pipeline. Sweeping/Ram взаимоисключены явным отказом на state/runtime/F1 без auto-OFF. Начатая очередь заканчивает старый профиль, смена на свободной границе; identity/mount/upgrades/cooldown/летящие снаряды сохранены. OFF возвращает authored settings. После sector rebuild cooldown принадлежит новому runtime: перенос cooldown между секторами не заявлен.
6. **Успех/границы/отказ:** **cycle-74 — компиляция, четыре Passed, executed=4, failed=0**, точные методы ниже. Четыре отдельных неизменённых prefab-тела проверены по bounds/sweep внутри 3,5 м: ровно три попадания по 10/три направленных импульса, четвёртое без урона/импульса; фронтальный ShieldCollider увеличивает Blocks и завершает снаряд без damage/импульса за щитом. Это передача импульса, не визуальное движение толпы. Отказ: слабый Sniper без пространственного выбора, незаметное оттеснение или практически бесполезная короткая дальность.

**Проба:** Development MVP → F1 → первая вкладка → выключить веерную очередь → включить картечный таран → получить Shotgun штатной наградой → закрыть карточку/F1 → Tab, перетащить из запаса в O → закрыть конструктор → Q/E направлять линию. Осмотренные cycle-74 кадры показывают игрока, оружие, одиночный голубой снаряд/HUD при закрытых окнах и изменение направления конструкции; столкновение с толпой/интересный баланс ими не доказаны.

### Тактические враги: общий путь и ограничения

EnemySpawner назначает только подходящие ordinary-spawn текущего профиля; специальные/event/assault/boss/carrier/turret и неподходящие роли исключены. Ручная кнопка не расходует ordinary cadence, использует безопасное размещение и debugEnemies. Нет подходящего prefab/места — отказ без подмены. F1 → «Враги и события» → включить нужный эксперимент → соответствующая «+1…» закрывает F1; AI должен работать. Уборка — «Убрать созданных вручную врагов». OFF/reset/смена профиля/OnDisable владельца отменяют собственные живые назначения/pose; re-enable не возвращает opt-in. StopSpawning сохраняет прежнюю семантику. Стрелковые volley/strafe/recoil взаимно исключены; отклонённое включение не сбрасывает fireTimer. Контактный урон, authored projectile и внешние силы не меняются.
