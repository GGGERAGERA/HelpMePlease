# Атмосферные реплики MainMenu

**Цель / спецификация:** прямой запрос пользователя от 31.10.2026: небольшое облачко над персонажем, три категории, редкие случайные реплики, реальные комнаты, подавление интерфейсами, Inspector и программный API, без новых зависимостей. Последующее уточнение заменяет первоначальные 3–4 с медленным набором при 95 словах/мин и 1,5 с на дочитывание; облачко поднято над головой и использует существующий пиксельный шрифт.

**GDD:** [Bible §9.2–9.4](../../../Assets/_Project/Documentation/Subject42_Game_Design_Bible.md#92-пять-обязательных-функций), [Core §7](../../../Assets/_Project/Documentation/Subject42_Game_Design_Bible_Core.md#7-бункер). Сверка 26.10 не доказывает реактивный дом; проверяем актуальную MainMenu.

**До → после:** молчаливое перемещение по бункеру → короткие необязательные реакции на пространство и события. Решение игрока: можно задержаться ради атмосферы, но чтение и остановка не требуются; управление, награды и прогресс не меняются.

**Основание:** прямой запрос пользователя; принято в указанном объёме. Доказательств влияния на игроков пока нет.

**Архитектура:** scene-owned `BunkerAmbientBarks` со списком (текст, категория, ключ комнаты/события, вероятность); `BunkerBarkView` на отдельном Canvas без raycast; `BunkerBarkRoomTrigger` на реальных комнатах. Использовать существующий кириллический шрифт, BunkerPanelManager, intro, minigames и fullscreen/summary roots. Комната > событие > случайная; немедленный повтор текста запрещён, повторный вход в ту же комнату ограничен 90 с. Случайный таймер 60–120 с после любой принятой реплики; при блокирующем UI время не накапливается, запросы отбрасываются.

**Подход:** отдельная лёгкая система в существующей сцене; общий dialogue framework и изменение существующего управления не требуются. Authoring через Editor сохраняет явные scene references и коллайдеры, не bootstrap runtime.

## Настройка

### Коррекция подачи по отзыву пользователя

**GDD:** Bible §9.3 / Core §7 (ссылки выше). **До → после:** облачко с полным текстом на 3,6 с перекрывает часть персонажа → поднятое пиксельное облачко с посимвольной речью при 95 словах/мин (Inspector 90–100), затем 1,5 с на дочитывание и fade. Прежний фиксированный лимит 3–4 с пересматривается прямым запросом пользователя: он несовместим с медленной речью длинных фраз. Необязательное чтение по-прежнему не останавливает движение. **Основание:** пользователь наблюдал перекрытие персонажей и просит более стильную, медленную речь. **Проверка:** короткий тот же smoke, полный текст не открыт после первого fade; темп соответствует числу слов, вся фраза успевает набраться; снимки в процессе и после набора, зазор над головой. Переработать, если текст перекрывает героя или исчезает до завершения набора.

В MainMenu: `SYSTEM / Bunker Ambient Barks / BunkerAmbientBarks`, список `Lines`. `Room` использует ключи `arcade`, `chill`, `gallery`, `trophies`. На дочерних объектах `Ambient Entry - …` соответствующих комнат находятся реальные BoxCollider2D и ссылки на контроллер.

`Event` использует произвольный строковый ключ; production-итог забега вызывает `return_from_run` после закрытия своего окна. `story_reflection` — готовая нейтральная реплика для будущих событий.

```csharp
BunkerAmbientBarks.Instance?.TryPlayEvent("story_reflection");
BunkerAmbientBarks.Instance?.TrySpeak("Короткая реплика NPC.", npc.transform);
```

Методы возвращают `false`, если интерфейс подавляет показ, сработала защита повтора или уже звучит более приоритетная реплика. `PlayEvent(string)` также доступен для Inspector UnityEvents. Новые блокирующие интерфейсы добавляются в `Blocking Interfaces`; постоянный HUD и пассивные подсказки управления не являются модальными интерфейсами.
