# Обходчик и Проломщик — production MVP

**Goal:** доработать два существующих прототипа и добавить их в обычные волны.
**Architecture:** локальные дополнения EnemyChaseMovement и EnemyCollisionHandler; два prefab-варианта существующего ближнего врага, отдельные записи в существующих профилях. Без новой AI-архитектуры.
**Tech Stack:** Unity 6000.3, C#, NUnit/Unity Test Framework.
**Spec:** прямой запрос пользователя от 31.10.2026; исполнение в текущей рабочей копии, без Git-мутаций.

## Дизайнерское решение до реализации

1. **GDD:** [Bible §4.4 «Контроль толпы»](../../../Assets/_Project/Documentation/Subject42_Game_Design_Bible.md#44-контроль-толпы), [§2.1 / §2.2: читаемость и контр-игра](../../../Assets/_Project/Documentation/Subject42_Game_Design_Bible.md#21-законы-игрока); Core §4 «Проверка любого нового врага». Состояние сверено с [сверкой 26.10](../../gdd-reconciliation-2026-10-26.md) и текущими кодом/данными.
2. **До → после:** F1-прототипы, возврат Обходчика к кружению при удалении игрока, независимые тараны и контактный урон восстановления → отдельные production-варианты: одна фланговая дуга (до 3 с или дистанции 4 м), затем обычная ближняя атака; Проломщик: 0,65 с подготовки, 0,45 с фиксированного рывка, 1,2 с неподвижного восстановления без контактного урона. Общий допуск удерживается до конца восстановления и ещё 0,35 с. Игрок учитывает боковой заход, уходит поперёк зафиксированной линии и использует окно восстановления.
3. **Основание:** прямой запрос пользователя. Принят перенос в MVP; частота и субъективная читаемость остаются гипотезой до наблюдения за игроками.
4. **Проверка:** короткие целевые тесты окончания дуги, фиксации направления, взаимного исключения рывков, безопасного восстановления, снятия временных модификаторов и production-пула; один короткий сценарий MVP. Отказ/пересмотр частоты, если угрозы визуально теряются или восстановление не даёт использовать окно. Длительных прогонов и общего балансного плейтеста нет.

## Ограничения и выбранные параметры

- Существующие HP, урон, loot, спавнер и графика наследуются от обычного ближнего врага; стартовая локация использует вариант с прежними 8 HP.
- В каждую фазу действующих профилей добавить Обходчика с весом 8 и точным лимитом 2; Проломщика с весом 5 и точным лимитом 1. Старые записи, веса, общий cap и темп сохраняются.
- Оружие, орбитальная система, награды, события и сохранения не меняются.
- Временный внешний множитель скорости использует существующий SetAnomalySpeedMultiplier; для восстановления добавить локальный API по источнику с явным удалением. Подготовка и направление не ускоряются.
- Debug-переключатели остаются изолированы от production-вариантов; production не помечает попытку Development.

## Review focus

- Удаление игрока после сближения не перезапускает дугу; таймаут предотвращает бесконечный обход.
- Пауза/заморозка/смерть/disable не оставляют занятый допуск рывка.
- Контакт во время восстановления не наносит урон; HP врага остаётся штатным и доступным для атак.
- Модификаторы не копятся при повторной установке и снимаются по источнику / disable.
- Новые варианты не попадают в подбор существующих событий и не получают debug-переназначения.
