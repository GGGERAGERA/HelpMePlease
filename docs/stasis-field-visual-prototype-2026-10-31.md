# Синяя зона стазиса — визуальный прототип WorldSystemsLab

Статус: художественный эксперимент по прямому запросу пользователя от 31.10.2026; перенос в production не разрешён.

1. **GDD:** [Bible §6.2 — читаемость правила](../Assets/_Project/Documentation/Subject42_Game_Design_Bible.md#62-контракт-world-rule), [§6.5 — существующая синяя аномалия и Q/E](../Assets/_Project/Documentation/Subject42_Game_Design_Bible.md#65-текущая-реализация-и-границы). Core и [сверка 26.10](gdd-reconciliation-2026-10-26.md) прочитаны; сверка не заменяет текущие данные и runtime.
2. **Изменение:** дебажная заливка прямоугольника → нанесённое на существующую землю технологическое поле: концентрические сегментированные дуги, циановая прерывистая граница, плоские узлы, гравировка и мягкие бегущие импульсы. Улучшается распознавание территории перед входом; решение входить или выходить и правила замедления прежние. UI лаборатории увеличен: основной текст 18 px, кнопки 40–42 px; конструктор увеличивается только в этом эксперименте.
3. **Основание:** пользователь просит законченный художественный прототип одной синей зоны, сохранив землю, читаемость боя, все границы и механику. Production MVP и другие зоны не меняются.
4. **Проверка:** короткий сценарий Play Mode в существующей WorldSystemsLab: исходный BoxCollider2D без изменений; движение игрока/врага ×0,65, Q/E 45°/с и расход 25/с; восстановление после выхода; отсутствие коллайдеров у нового декора. Просмотр настоящего Game View 1600×900 с орбитальным оружием и связями, второй кадр для анимации. Отказ от эксперимента при несовпадении границ/механики, закрытии земли, появлении препятствий либо потере читаемости боевых объектов. Сборка и длительные тесты не нужны.

## Реализация и границы

Новый визуал создаётся только WorldSystemsLabController для Stasis и дополнительно защищён проверкой точного пути сцены. Production-префабы, материалы, данные и механический код не редактируются. Исходные рендереры только этой территории скрываются через forceRenderingOff; исходный коллайдер и обработчики не изменяются. Один SpriteRenderer, две небольшие однократно созданные point-filtered текстуры, один unlit URP 2D shader без частиц, света и post-processing. Текстуры/спрайт/материал освобождаются с зоной.

Команда Unity: Tools → Subject42 → Dev → WorldSystemsLab → Preview Stasis Art (1600x900). Запускает только короткую проверку синей зоны, оставляет Play Mode и обзор поля. Игровая камера кадрируется отдельно только для просмотра прототипа; обычный режим лаборатории продолжает следовать за игроком. Снимок: `Artifacts/GeneratedQA/StasisField/stasis-gameview-1600x900.png`.

## Результат

Короткий сценарий Play Mode завершён: 13 проверок PASS, включая отсутствие новых коллайдеров, неизменные исходные размеры/offset/enabled состояния зоны, движение игрока и врага ×0,65, Q/E 45°/с при расходе 25/с, восстановление при выходе, подключение нового оформления только к Stasis и отсутствие ошибок компиляции шейдера. Отчёт: `Artifacts/GeneratedQA/StasisField/result.txt`.

Просмотрены два настоящих снимка Game View 1600×900, полученные с интервалом 1,1 с: `stasis-gameview-1600x900.png` и `stasis-animation-1600x900.png`. Видны существующий пол/декор, персонаж, пять лабораторных врагов, снаряды, оружие и подписи связей; импульсы меняют яркость и положение вдоль дуг. Энергетические узлы плоские. Прямоугольные габариты повторяют исходную FocusArea текущей автоматически создаваемой раскладки лаборатории; seed и правила раскладки не изменялись. Оранжевая штриховка за территорией — прежняя граница лабораторной карты.

Для кадра используются существующие функции спавна и бессмертия лабораторных врагов, а для обзора — временное кадрирование камеры. WASD либо переход в другую зону возвращает обычное слежение камеры. UI аномалий расширен до 460 px, кнопки 42 px, текст 18 px; увеличение конструктора включено только при активном эксперименте этой сцены.

Unity оставлена в Play Mode в существующей WorldSystemsLab. Проверка механики выполнена коротким программным сценарием через существующий runtime; это не физический ввод и не ручное прохождение отдельной сборки. Сборка, длительные тесты и коммиты не выполнялись. Production MVP, production-данные и другие зоны не редактировались. Перенос в production и окончательное принятие художественного направления остаются отдельным решением пользователя.
