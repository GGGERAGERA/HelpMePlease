# Интерфейсы станций — 22.10.2026

Все четыре станции используют один экземпляр утверждённого `CharacterSelectionWindow.prefab`. Имя файла, GUID и исходные компоненты сохранены ради сериализованных ссылок. Убрана только лампа слева от «УЛУЧШИТЬ», подпись со стоимостью выровнена по центру.

## Фактическая архитектура

```text
BunkerPanelManager → SelectionPanelController
  → CharacterSelectionWindow.prefab (единое окно)
    StationUIShell: рамка PNG, шапка, золото, области, нижние кнопки
    BunkerSelectionWindow: каталог, выбор, жизненный цикл источника
    BunkerSelectionCardView: общая карточка, выделение, блокировка
    BunkerSelectionDetailView:
      DetailContent: исходная платформа, персонаж, скрытые субъекты, характеристики
      BunkerStationItemDetail: изображение предмета, эффект, характеристики
    BunkerProgressionView + HoldInvestmentInput: вложения, стоимость, уровень, состояния
```

Оружие, улучшения и аномалии используют предметный блок; персонажи — исходный специализированный блок. Карточки предметов компактнее карточек персонажей. Закрытые персонажи не раскрывают имя, изображение, особенность и характеристики.

Контент задаёт `BunkerSelectionCatalog`. Существующие адаптеры `BunkerSelectionSourceHub` и сервисы прогрессии отвечают за свои данные и экономику. Новых параллельных контроллеров покупок нет. Общая рамка меняется в одном prefab и используется каждой станцией. Старое окно сохранено для совместимости с лабораторными сценами.

## Предметы и цвет

- Оружие: реальные составные спрайты боевых prefab, включая стволы и оттенки. Синий «Импульс», красный «Луч», зелёный «Залп», фиолетовая «Пила». PNG каталога воспроизводимо собираются редакторской командой из игровых спрайтов.
- Улучшения: игровые иконки характеристик и сравнение текущего и следующего значений.
- Аномалии: существующий знак аномалии, короткий эффект, фиолетовый акцент; условия открытия сохранены.
- Циан обозначает выбор и результат, янтарный — затраты, красный — ограничения и недостаток золота.

## Проверка

Снимки сделаны через `ScreenCapture` из настоящего Play Mode при **1600×900**, отдельно RU и EN. Проверки используют реальные пути `BunkerPanelManager`, кнопки карточек и события указателя для удержания; физическая мышь не проверена: Windows Capture возвращал таймаут.

Проверяются открытие и закрытие всех станций, карточки и блокировки, скрытые субъекты, удержание улучшения предмета и станции, точность списания, отмена удержания при смене станции, недостаток золота, максимум уровней, смена языка, переполнение текста и повторное открытие. Отдельный сценарий проверяет распространение изменения общей рамки на все станции и независимость предметного блока от портрета персонажа. Тесты сохраняют и восстанавливают значения прогресса; сравнение после восстановления проверяется автоматически.

**Результат: 7/7 целевых проверок прошли.** Включены проверки производственных сериализованных ссылок и RU/EN. Release и Development scripts компилируются; найденные предупреждения относятся к существующим устаревшим API проекта. Независимый обзор не выявил замечаний.

Снимки и XML результатов находятся в `Artifacts/GeneratedQA/BunkerStations`: `characters-ru.png`, `weapons-ru.png`, `upgrades-ru.png`, `anomalies-ru.png`; EN — файлы `0-English.png`…`3-English.png`. Основной результат — `results.xml`, компиляция — `compilation.txt`, восстановление 42 ключей — `preferences-restored.txt`, ссылки prefab — `prefab-reference-audit.txt`.
