# Subject#42 — визуальный прототип

Откройте `CharacterSelection.unity` и вкладку Game (1920×1080).
Это статический Canvas: кнопка и карточки — только изображения и текст.
Выбор, сохранение, разблокировка и переходы отсутствуют.

Все новые ресурсы находятся в этой папке. Сцена не добавлена в Build Settings.
Спрайты в `Sprites` заменяемые: Point, без mipmaps и сжатия;
`Frame9Slice` имеет границы 8 px. Основной портрет — 192×192.
Используется существующий пиксельный шрифт Press Start 2P без изменения его настроек.

Редакторская команда `Tools > Subject42 > Build isolated character UI prototype`
пересоздаёт только этот прототип и его снимок в
`Artifacts/Subject42UIPrototype/CharacterSelection.png`.
Перед пересозданием закройте сцену прототипа; ручные изменения макета будут заменены.
