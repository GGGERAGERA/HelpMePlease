# F1 — этап 2: навигация и дубликаты

Спецификация: запрос пользователя от 30.10.2026 и [инвентаризация](F1_Inventory.md).

Цель: компактная навигация внутри существующего Subject42DebugMenu. F1 открывает Песочницу; шесть разделов используют текущие builders и обработчики. Поиск и избранное остаются в Hub, «Назад» возвращает предыдущую страницу. Новые менеджеры, другая UI-система и изменения gameplay исключены.

Это рефакторинг debug UI, не изменение геймдизайна: правила боя, награды, сохранения, геометрия Segmented и контракт Development не пересматриваются. Общие реализации и внешние input API сохраняются. Данные аудита — исходные ориентиры, актуальные callers проверяются по исходникам.

Проверка должна различать просмотр исходников, исполнение UI-сценария и ручной физический ввод. Smoke не доказывает исполнение всех игровых действий.

## Результат

Существующая F1 открывает Песочницу. Шесть кнопок разделов заменяют скрытые старые вкладки. «Поиск / избр.» открывает прежний Hub; «Назад» хранит и страницы инструментов, и Hub с поисковым запросом. ID избранного сохранены; старые visual.original/current/custom отображаются как visual.studio, run.sectors как run.tools. Режимы сравнения остаются внутри Studio.

Физически удалены три builder-блока, qaSection, SelectQaSection, SetDebugThreatTier, AddProductionSpecialOverride, SpawnBoss, KillBoss, OpenLevelCards, ToggleTacticalMap и отдельная Destroy-all реализация KillAllEnemies с кнопкой «УБИТЬ ВСЕХ». У этих локальных членов подтверждено отсутствие оставшихся callers. CompleteLevel, FindAliveBoss и production API сохранены.

Убран QA → OrbitalProduction и повторные переходы QA → FEEL/production visual. Один каталог предметов и отдельная страница карточек используют прежние обработчики. Auto Spawn, Freeze AI и Clear Manual находятся на одной странице «Враги и бой»; плотность, ordinary cleanup и тестовый босс перенесены туда же. Sandbox использует общие setters; параметр captureSettings сохраняет прежнюю capture-сессию, её cleanup и Development-контракт. У обычного переключателя автоспавна по-прежнему нет неявного захвата сессии. Clear Manual и ordinary cleanup остаются разными действиями.

В «Мир и прогресс» собраны здоровье, XP, pickups, штатные переходы, события и World Rules. Прямая выдача XP не заменена созданием кристаллов, области очистки дропа не объединены, тестовый босс не подменяет завершение сектора.

Все шесть вариантов оружия и восемь экспериментов врагов сохранены по исходникам, полный набор перенесён в QA. Шесть быстрых вариантов оружия остались и в Sandbox. FEEL LAB, боты/Golden Path, диагностика, MainMenu bunker, Live Visual Studio, F9, runtime-конфиги и внешние IsDebugMenuOpen / HubBlocksGameplayPointer / HubBlocksKeyboardInput / RestoreBotResumeScale сохранены. Legacy visual остаётся одним явно обозначенным расширенным инструментом QA; общие лабораторные реализации не вырезались. RingPower/LinkPair/Core в production F1 не добавлены.
