## Что действительно составляет F1

F1 открывает **Debug Hub с четырьмя категориями и 14 командами**, без паузы. Команды открывают детали MVP или страницы старого меню через `hubLegacyLab=true`. Четыре MVP-страницы существуют, но их tab bar скрывается `HubApplyDetailsLayout`; это не четыре непосредственно видимые вкладки Hub. Старые страницы: Bunker, PlayerBuild, WorldEvents, Additional, OrbitalProduction, FeelTest, VisualTest. Не все из них доступны в MVP одинаково.

**Отдельного F1 prefab в MVP нет.** `BootstrapDevelopmentMenu/AttachDevelopmentMenu` (S:252–269) добавляют компонент к найденному `HUDManager`. `BuildHub` (H:66) и `BuildMenu` (S:859) создают Canvas/uGUI/TMP/ScrollRect и подписки кнопок кодом; persistent UnityEvents prefab для этих кнопок нет. Нельзя инвентаризировать F1 только по YAML. В MVP есть EventSystem с input module; menu использует старый `Input.GetKeyDown(KeyCode.F1)`.

`MvpCanEdit` требует инициализированную station, живого owner, UpgradeManager с пустой очередью и отсутствие перехода. Оружейная страница дополнительно требует `UsesSegmentedOrbit`. `CharacterSpawner` всегда вызывает `OrbitalStationRuntime.Ensure(... segmentedOrbit:true)`; обычное оружие `BaseWeapon` не создаётся, `PlayerWeaponOrbitVisual` отключается. Открытие MVP в Editor само по себе не доказывает, что активен допустимый ран.

### Live Visual Studio — полное дерево генераторов UI

Это отдельный runtime-built editor, доступный через F1, поэтому включён в аудит. Список targets и shader parameters зависит от живой сцены и материалов; статический prefab не задаёт их число. Ниже полностью перечислены правила генерации, а не выдуманный фиксированный список экземпляров. Каждая numeric property создаёт slider + числовое поле + `-` / `+` + `Сброс` + `+/*` favorite; есть текущее/Current/Git значения. Цвет добавляет HEX и HSV, затем каналы RGBA (если у property есть alpha).

## Предлагаемая структура F1 — 6 разделов

Предложение навигации, без реализации и без изменения игровых правил:

1. **Билд и награды** — 4 оружия, 4 модуля в запас; открыть орбиту; +1 лимит оружий; каталог шести характеристик с обычной карточкой и eligibility. Единственный вход, текущие handlers UM/reward flow.
2. **Бой и арена** — current-profile enemy catalog +1/+10; auto-spawn; density 0,5/1/1,5/2; fill; freeze AI; clear ordinary / manual; Assault presets; test boss; dummy. Отдельные подписи областей очистки.
3. **Игрок и ран** — heal/invulnerability/HP50%; XP до уровня; medkit/magnet/XP field + scoped cleanup; phase/sector/reward state; завершение доступного сектора; возврат в бункер. Пауза деталей сохраняет явный owner, Hub live.
4. **Мир и события** — World Rules, threat, clear events, RocketStorm, reward chest, portal pair, regenerate resource nodes. Flow final boss остаётся в «Игрок и ран», тестовый encounter — в «Бой и арена».
5. **Визуал** — одна команда Live Visual Studio с текущими targets/Original/Current/Custom/profiles; F9 как shortcut на ORBITAL rings. Legacy PLAYER RING/Weapon/Projectile controls не рекламировать для Segmented.
6. **Диагностика и лаборатории** — snapshot/logs; bots/seeds/batches; закрытые 6 weapon + 8 enemy + 2 event experiments; FEEL с точной поддержкой target pipeline; ссылки/входы lab tooling только там, где реально существуют. Бункерные persistent tools доступны в бункере.

Это не предложение нового manager/service: сохранить production ownership, сократить повторные UI builders и точки входа. Неподключённые FEEL consumers не «чинить» общим runtime fallback в рамках перестановки меню.

### Наиболее существенные фактические дефекты и долг

1. **Навигация слоистая:** Hub скрывает tab bar, но продолжает использовать старые enum indices/pages плюс hubLegacyLab. Отсюда повторные «Орбиты», скрытые старые builders и расхождение «Секторы и босс» с фактическим набором команд.
2. **Неподключённые к MVP visual/feel controls:** legacy weapon/projectile renderer paths расходятся с Segmented; наличие generic registry consumer не гарантирует текущий source. Сохранить лабораторный смысл, не объявлять production-working.
3. **Legacy Visual Save/Reset из MVP:** baseline не загружается; save no-op, reset отказ. Preview overlay не создаётся. Legacy переход в ring appearance строит не ту страницу.
4. **Разные scopes и последствия под похожими подписями:** Clear ordinary/manual/all; «УБИТЬ ВСЕХ» делает Destroy; AddExperience vs loot spawn; test boss vs final route; четыре разных формата Save.
5. **Development tagging не единообразен:** reward debug/experiments/pickup tools/capture sessions маркируют run; прямой MVP Heal, QA SpawnDebugEnemies/SpawnDebugExperience, ForceAssaultEvent и секторные chest/portals/nodes сами такого вызова не содержат. Анализ не менял прогресс/баланс; перед рефакторингом выбрать единый contract для влияющих на игру debug actions, а не предполагать, что весь F1 автоматически исключает production credit.
6. **Не все названия ORBITAL устарели:** actual station/runtime, Studio config, bot damage telemetry и Orbital Relay остаются реальными production concepts. Устарели конкретные nonsegmented/Core/paired-node modes, а не папка/термин целиком.
