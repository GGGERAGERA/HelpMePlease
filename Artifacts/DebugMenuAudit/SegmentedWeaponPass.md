# Segmented MVP — оружейный срез, 31.10.2026

GDD: [§4.5 «Рост силы»](../../Assets/_Project/Documentation/Subject42_Game_Design_Bible.md#45-рост-силы), [Core — рост силы](../../Assets/_Project/Documentation/Subject42_Game_Design_Bible_Core.md#рост-силы).

До реализации: заряженная линия получает читаемые накопление/выстрел/затухание через существующие presentation и FlashLink/pool, AudioService и CameraShake; 0,45 с, урон 24, три тела, радиальная линия, скорость, дальность и хитбокс сохраняются. Дробовик остаётся прежним семидробинным; два его эксперимента удаляются после проверки consumers. Пила временно исключается из production-наград, выдачи и новых установок; прежние экземпляры безопасно сохраняются в запасе, lab backend остаётся. В F1 только две группы — пистолет и снайперка.

Основание: прямой запрос пользователя — слабое ощущение заряженного выстрела и текущая гипотеза радиальной стрельбы. Пистолет и его возврат промаха не меняются. Временное исключение пилы — эксперимент состава оружия, не пересмотр общих боевых компонентов; пересмотреть по ручному сравнению билдов, если исключение обедняет позиционные решения. Удачное восприятие VFX требует ручного наблюдения и не выводится из автоматического PASS.

План и критерии:

- [x] Усилить только presentation заряженной снайперки: сине-белая зарядка, акцент последних 0,1 с, указание направления, короткий луч с ядром, muzzle/impact flash, локальный recoil, существующие звук и краткая камера. Не менять физику выстрела.
- [x] Удалить Shotgun experiments/handlers без удаления shared burst/knockback/settings и полезных лабораторий; обычный профиль сохранить.
- [x] Ограничить Saw только в production и сохранить совместимость/идентичность старых предметов; актуализировать F1.
- [x] Обновить Bible §4.5 и Core в этой работе; прежние исторические срезы явно уточнить новым решением.
- [x] Editor compile и один короткий smoke: F1 → charged sniper/зарядка/выстрел → обычный дробовик → отсутствие пилы в production pool/выдаче/новых установках и безопасный restore. Без сборок/массовых тестов/Git mutations. Оставить MVP открытой.
