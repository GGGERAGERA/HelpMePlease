Bunker women — ten new female idle sprites, 2026-10-31

Native format: 50x50 RGBA canvas; 27x39 silhouette including dark outline;
centered at x12..38, y11..49; feet baseline49; alpha only0 or255;
maximum16 flat visible palette colors per sprite; no dithering or antialiasing.
These are standalone idle art assets, without gameplay or animation integration.

Generated with built-in image_gen.imagegen, one call per character.
Style references: the original Gera sprite and the earlier bunker resident sheet.
Prompts, design descriptions and palettes: manifest.json and prompts/.
Unmodified generated originals: sources/ in this workspace.
Export: nearest-neighbor sampling of source alpha bounds, fixed palette
quantization, binary alpha threshold128, silhouette boundary recolored charcoal.
Sampled bounds are normalized to27x39 if an extreme row or column is lost.
Pixel-level checks are recorded in validation.json; previews enlarge by integer factors.
Contact-sheet labels/background are separate from the transparent native sprites.

The ZIP contains the ten PNG sprites, previews, transparent atlas, contact sheet,
prompts, manifest, README and validation report. Large source images stay in sources/.
