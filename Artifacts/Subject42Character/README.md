# Subject#42 — idle character

One downward-facing idle pose, slightly viewed from above. Native canvas: 32×32; visible silhouette: 14×27. Each sprite uses 7–8 opaque colours and transparent background, with binary alpha only. No animation has been created.

Comparison order, left to right: Base (cyan forearm implant), Hood_Cyan, Shaved_Amber, Lab_Violet.

Editable Aseprite sources have separate body and anomaly layers. Comparison is a direction-selection board, not an animation sheet. Preview PNGs are enlarged with nearest-neighbour sampling; use the 32×32 PNGs in Assets/_Project/art/Sprites/Subject42Idle for the game.

Unity import metadata: Sprite / Single, 32 PPU, Point, Clamp, no mipmaps, uncompressed, custom pivot (0.5, 0.09375) at foot level. Existing scenes and player prefabs were not modified. In-game readability among effects still needs gameplay review.

Created using Aseprite's native Lua pixel API. The Lua files preserve the source pixel layout and variant transformations. validation.txt records checks of exported PNGs and reopened native files.
